---
description: Deploy
---

Compila y despliega el proyecto en el VPS de Oracle.
1. Ejecuta `npm run build` para validar que el build de Vite sea correcto.
2. Si el build tiene éxito, ejecuta el script de despliegue `bash scripts/deploy_vps.sh`.
3. Reporta la URL de producción (https://cesaunison.fondothoth.com) cuando termine.
